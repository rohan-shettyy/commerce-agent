Project Overview
Build a full-stack, production-grade AI commerce assistant — inspired by Amazon Rufus — with a single unified agent that handles:

General conversation — greet users, explain capabilities

Text-based product recommendation — natural language queries like "I need running shoes under $80"

Image-based product search — upload a photo to find visually similar products

Voice-based product search — speak a query, receive spoken + visual results

The agent is one entity exposed through four input modalities; it is NOT four separate agents.
